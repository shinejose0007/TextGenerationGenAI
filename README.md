
# SmartCity — Generative AI Demo (Text Summarization & Drift Detection)

A complete proof-of-concept project demonstrating **Generative AI**, **ETL data pipelines**, **Transformer fine-tuning**, **model evaluation**, **drift monitoring**, and **deployment via FastAPI and Streamlit**.

Developed as a demonstration of end-to-end **Data Science & MLOps skills** relevant to roles such as **Data Scientist – Generative AI** 
---

## 🧠 Overview

This project shows a realistic **data-to-deployment pipeline**:

1. **ETL / Data Integration:** Combine and clean multiple data sources (CSV, JSON, SQLite).  
2. **Generative AI Model Training:** Fine-tune a T5 transformer model on text summarization.  
3. **Evaluation & Monitoring:** Evaluate model quality and detect data drift using Sentence-BERT.  
4. **Deployment:** Serve inference and drift detection via a FastAPI microservice.  
5. **Visualization & Demo:** Streamlit UI for easy testing and stakeholder demos.  
6. **Orchestration:** Example Apache Airflow DAG for automated pipeline scheduling.  
7. **Metrics:** Prometheus integration for latency and drift monitoring.

## ⚙️ Installation & Setup

### Prerequisites
- Python **3.10+**
- (Optional) NVIDIA GPU with CUDA for faster training
- Internet access (for model downloads)

### 1️⃣ Create and activate a virtual environment
**Windows (PowerShell):**
```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install --upgrade pip
```

### 2️⃣ Install dependencies
```powershell
pip install -r requirements.txt
```

If `torch` fails to install automatically:
```powershell

pip install torch --index-url https://download.pytorch.org/whl/cpu
```

## 🚀 Running the Project (End-to-End Workflow)

1️⃣ ETL → 2️⃣ Train → 3️⃣ Evaluate → 4️⃣ Drift Baseline → 5️⃣ Threshold → 6️⃣ FastAPI → 7️⃣ Streamlit

Each step:
```powershell
python etl/etl.py                            ✅ Output: data/train_data.csv
python training/train.py                     ✅ Output: saved model + tokenizer under training/outputs/t5-small-experiment/
python training/evaluate.py                  ✅ Output:training/eval_results.csv
python monitoring/drift.py                   ✅ Output:monitoring/drift_threshold.npy


Run the FastAPI Service

Starts the inference + drift detection API.

cd service
uvicorn app:app --host 0.0.0.0 --port 8000


Endpoints:

POST /generate → Run text generation
POST /drift → Run drift check
GET /metrics → Prometheus metrics (port 8001)

Example:

curl -X POST "http://localhost:8000/generate" -H "Content-Type: application/json" -d "{\"text\":\"Zugausfall am Hauptbahnhof wegen Signalstörung.\",\"max_length\":80}"


Example drift check:

curl -X POST "http://localhost:8000/drift" -H "Content-Type: application/json" -d "{\"texts\": [\"Bus delayed at Central Station\", \"Water leakage near Market Street\"]}"


✅ Output:

{"drift_score": 1.0077, "threshold": 0.3767, "status": "ALERT"}


python monitoring/compute_threshold.py
cd service && uvicorn app:app --host 0.0.0.0 --port 8000
streamlit run streamlit_app.py
```
